# 后端公开阅读验证

2026-10-30，Windows / Python 3.12.4；后端端口按用户指定为 **8001**。这是公开阅读第一版验收，初始化验证保留为历史记录。

| 检查 | 实际结果 |
| --- | --- |
| 锁文件 | `uv lock --check` 通过，39 个解析包（含项目与平台条件包） |
| 静态检查/格式 | `uv run --locked ruff check .`、`ruff format --check .` 通过，原始基线排除 |
| 类型检查 | `uv run --locked mypy` 通过，34 个源码文件；覆盖 app/tests/tools |
| 单元及真实数据库测试 | 设置 `RUN_DATABASE_TESTS=1` 后 `uv run --locked pytest`，30 项全部通过 |
| 显式迁移 | 开发/测试专用库 upgrade head 成功，两个 Alembic check 均无模型漂移 |
| 网络就绪 | `http://127.0.0.1:8001/health/ready` 200，database/redis/schema 全 ok |
| 真实业务数据 | site 统计与 78/9/11/78/7 相符；文章分页、真实路径解析、公开评论通过 |
| 错误/跨源 | 超限页大小 422，未知路径 404；允许前端 Origin 的 CORS 头正确 |
| 依赖不可用 | 受控不可达地址验证 API/ready 为 503，没有停止用户 PostgreSQL 服务 |
| 契约 | 公开 OpenAPI 的 404/422/503/500 为真实错误外壳，前端按版本生成快照类型 |
| 导入幂等 | 重复相同中间产物新增 0、更新 0、changed=0，generation 稳定为 3 |
| 公开数据/媒体 | 快照递归无账户/联系信息字段；所有本地媒体映射指向存在文件，原备份未修改 |

测试重点包括：配置来源/类型/未知字段拒绝与脱敏；published+public 过滤和统计不泄漏；字面 LIKE/中文搜索；分页空页与错误；评论隐藏父节点/跨页父评论；MySQL 字符串与 PHP 数组解析；代码区不改写、链接节点处理和媒体边界。数据库测试显式拒绝开发库，统一事务回滚。

当前 87 篇公开内容快照约 1.1 MB，312 项媒体约 55.3 MB，4 个商城系统页和 3 条密码保护内容不进入公开数据。两个缺失 JPG 变体已匹配备份中存在的 WebP；7 个未导入同源路径保留为原站外链，不虚构本地功能。

## 未覆盖的能力

登录/权限写入、正式修订与审核、协同、Celery/Scheduler/Outbox、完整 ICP 与可靠撤回、镜像/CDN、生产安全日志和恢复演练均尚未实现或验收。本次数据源为固定备份的公开读取试导入，不是生产在线同步方案；不宣称完整 WordPress 迁移完成。

线上读取遇到 Cloudflare challenge，浏览器插件要求重新认证，本机浏览器工具随后因不能可靠识别当前 URL 停止操作；未绕过这些限制。外观依据为本地 Argon 源码、白名单公开设置和原背景/头像资源，没有本轮浏览器截图级视觉验收。当前阶段没有推送远程或部署。

## 可复现命令

在后端项目根运行根 README 的检查命令；真实 PostgreSQL 测试使用被忽略的 config.test.local.toml，并设置 RUN_DATABASE_TESTS=1。导入/导出工具命令、8001/3000 启动与手工验收见 docs/development/public-reading.md。新环境必须自行建立实例配置和数据，不能因 clone 缺少忽略目录误判代码已包含内容。
