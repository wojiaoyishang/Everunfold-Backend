# ADR 0130：前后端独立节点控制台

后端 `/_nodes` 管理投递目标，沿用独立运维会话。部署清单显式导入后，API、Worker 和其他后台用例从 PostgreSQL 读取同一个带修订号的运行清单。导入前保持原有文件模式。浏览器管理节点 ID、公开地址与启用状态，内部端点和环境变量引用由部署工具登记。清单变更、审计与重发意图同事务提交。删除或停用保留历史并撤销未确认投递的租约。

前端 `/admin/_nodes` 默认关闭。本机配置文件可预先登记多个后端，只有一个活动连接。前端服务器验证后端可达性。在线操作使用 FastAPI 校验站点管理员会话后签发的短期凭据，绑定本机来源、节点、动作、目标与配置修订。配置文件依然由前端服务器维护。连接真正离线时独立密码只授权本机诊断与切换。HTTP 响应、TLS 校验失败和浏览器会话错误不授权离线模式。

前端按来源分别读取内容副本，接收器连接变更后须重启。后端管理页面与前端在线概览共享监控契约；离线页面从本机读取实际副本。后端迁移为 `0053_frontend_node_registry`，settings-v1 契约为 1.38.0。
