# ADR 0042：可视化 HTML、Markdown 预览与字体库

日期：2026-11-03。状态：实施中，用户已授权本轮实现；验收前不视为交付。

HTML 块默认可视化，源码为同一块的独立视图；Markdown 保留源码并增加预览/分屏。保留稳定块 ID、一篇草稿一个 Y.Doc、本人撤销、原媒体及提交后 ACK 管线。富文本使用 Tiptap/ProseMirror 的结构化共享片段；不以每次序列化整段 HTML 覆盖 Y.Text 实现协同。旧源码保留，不能表达的 HTML 保留为原始片段。源码暂存、应用时检查版本；源码编辑的临时所有权须由服务端落实，不能只依靠在线状态。

字体库为独立注册导航，复用不可变媒体、多文件进度队列、哈希复用、引用守卫及安全删除。允许 WOFF2/WOFF/TTF/OTF，单文件 20 MiB，读取实际字体表；名称与 CSS 家族标识分离。数据库仅保存媒体元数据和稳定 ID；Base URL/CDN 仍由已有配置解析。字体声明使用 font-display:swap，仅被使用的字体触发浏览器字体下载。

新增依赖以官方 React/Yjs 兼容信息及锁文件为准；不引入新协同服务。每完成可见组件即检查内置浏览器；数据库迁移显式执行，真实多进程验证和未覆盖项记录到交接。
