# ADR 0186 请求日志的客户端 IP

后台「真实 IP 来源配置」由浏览器会话中的站点管理员管理。规则保存在站点设置的私有数据中，有独立修订号和保存审计。FastAPI 定期刷新本机规则，已启用前端使用现有的节点地址白名单与令牌从内部接口获取同一份规则。无数据库迁移或公开快照改动。前端每约 15 秒读取，长期无法刷新时最多保留旧规则一分钟，随后使用直连地址。

请求日志区分直连地址、各请求头中可识别的 IP 和规则采用的地址。代理链从直连端向外查找第一个不在信任范围的地址，遇到无效项时按设定回退。缺少有效规则时使用直连地址。节点同步、控制台、监控和其他鉴权继续独立验证实际连接来源。

诊断由当前浏览器分别请求 FastAPI 和 Node.js，展现两端收到的地址值与生效修订。后端仅向站点管理员发放绑定到当前前端节点的一分钟诊断凭证，前端验证后仅返回这次请求的观测结果。持久令牌和其他请求头值留在服务端。
