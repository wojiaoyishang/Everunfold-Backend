# ADR 0137 · 页面类型与页面实例

2026-11-13。用户要求一个页面类型可以创建多份配置独立的页面。

部署清单的条目是页面类型。后端只登记类型 ID、版本、字段及默认值，路径仅为建议。节点重新登记不会创建页面、占用路径或更新现有页面配置。所有启用节点的定义一致后可发布该类型的页面。

后台通过 `GET /v1/admin/pages/types` 读取类型目录，含当前页面数量。自定义 HTML、CSS、JavaScript 页面使用内置类型 `core.custom`。新建时传 `type_id`，旧调用省略该字段仍创建自定义代码页。选择类型后按默认值创建草稿，每个实例独立保存 UUID、路径、配置、草稿修订及应用修订。类型在首次保存后固定。回收和恢复只作用于所选页面。

迁移 `0057_page_types` 将现有插件实现 ID 保留为类型 ID，将自定义代码页归入 `core.custom`。迁移保留页面 UUID、路径、内部元数据、评论、语言关系与公开快照。公开快照继续通过原有实现 ID 和版本定位渲染组件。通过类型计数统计插件使用，每个已应用的实例计一次。

部署先显式执行迁移，再更新 API、Worker、Scheduler 和前端。契约为 pages-v1 1.12.0 与 settings-v1 1.41.0。迁移回退会恢复每类只能有一页的唯一约束，已有同类型的多个实例时回退会由数据库拒绝。
