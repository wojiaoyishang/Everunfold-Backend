# ADR 0181 外部前端接入与同步来访诊断

状态：已实现，2026-11-17。

宿主机绑定 IP、容器内监听地址和发布 URL 是独立配置。统一部署允许分别发布前端与后端。容器外节点使用自己的节点 ID、配对令牌和接收器地址；后端按真实连接对端和节点令牌放行，不信任转发头。同步请求复用待投递任务，Worker 继续使用既有接收器鉴权、重试与确认机制。`deploy/node_bundle.py --node <id>` 可为 YAML 已声明的节点登记绑定并导出连接包，保留当前向导的默认配对。

后端节点控制台的「同步来访记录」覆盖主动同步、按需恢复与扩展清单上报。启用控制台时，API 进程将请求结果写入同一部署的运行 Redis，保留最近 24 小时和最多 4000 条；Redis 故障时请求处理继续。只记录时间、经校验的节点 ID、直连 IP、请求类型、状态、固定原因代码及令牌校验结果，不保存令牌、请求体或完整 URL。来源或节点校验阶段拒绝携有令牌的请求时显示「未校验」。

统计沿用 `/_nodes` 的认证、HTTPS 代理信任和禁止缓存策略。界面按时间范围统计来源与请求量，并按相同来源、节点、请求、令牌校验和处理结果合并，显示最近 100 组。同步受理表示请求进了队列，或已有在途任务；投递结果仍从节点状态读取。无需迁移，不改公开 API 契约。
