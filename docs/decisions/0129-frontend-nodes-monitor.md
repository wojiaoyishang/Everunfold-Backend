# ADR 0129：前端节点监控

后端通过 `frontend_nodes_file` 读取独立 TOML。API、Worker、Scheduler 和部署工具共享加载结果；稳定节点 ID、双向凭据引用和数据库现有版本记录沿用原定义。同一实例使用独立文件或内联节点配置之一。

`/_nodes` 是部署配置控制的后端运维插件，FastAPI 显式挂载。常规插件路由依赖站点记录和用户授权，运维页独立验证配置密码，数据库和 Redis 故障时仍可登录。页面只读取脱敏状态，渲染资源与路由同目录。

节点上报、投递回执与实时探测分别展示。探测沿用接收器实际 socket IP 和 Token 校验，在磁盘上验证当前绑定的完整版本，返回版本及副本状态。主项目业务同步协议保持兼容。settings-v1 1.37.0 增加探测响应定义，无数据库结构迁移。部署见[前端节点监控](../development/nodes-monitor.md)。
