# 0190 节点连接在线配置

后端部署控制台 `/_nodes` 可以添加带独立凭据的节点，也可以在线修改已启用节点的接收器、传输设置、双向令牌和入站来源 IP/CIDR。后端读取实际 socket 来源。节点使用专属来源规则时覆盖部署默认规则，继承时沿用 `internal_auth.allowed_peer_ips` 和部署派生的网络地址。

PostgreSQL 的 `frontend_node_registry.bindings` 保存连接配置和逐节点来源规则。使用应用主密钥按节点 ID 和方向派生 Fernet 密钥，现有部署环境变量继续提供未在线更改的方向。失去主密钥时，已加密的令牌不可用。控制台只返回令牌是否已配置，日志和审计记录变更结果。受授权的后端部署导出读取当前生效值。沿用现有 JSONB 字段，无需迁移。

在清单锁内提交连接变更、审计和投递意图。已启用节点更改接收器或出站令牌时撤销未确认的租约并重发当前版本。单独部署的前端由运维更新自己的连接配置，统一部署的本机前端在下一次 `start` 同步在线令牌覆盖值。前端接收后端调用的来源规则继续由前端部署配置控制。

[ADR 0165](0165-pairing-runtime-and-frontend-origins.md) 中令牌、来源规则仅能在 setup 修改以及更换接收器前停用的约定由本决策更新。
