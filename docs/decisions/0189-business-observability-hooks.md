# ADR 0189 业务事件日志

API 与 Worker 通过后端插件注册表发布不可变的业务结果。插件沿用已同步版本与启用状态，并在调用进程内处理。持久成功从各业务事务提交处登记。API 同时观察指定操作的 HTTP 拒绝，关联应用访问日志的请求 ID。幂等回放不登记新的成功事件。二次验证等待与登录成功分别记录。

通知以投递状态为准。站内通知在写入收件箱后记录。SMTP 接受、拒绝、跳过和结果未知分别统计。注册、验证和找回密码的安全邮件沿用各自的投递队列，在结果提交后使用同一个业务事件格式。

本插件提供尽力投递的结构化日志。业务数据与通知正文留在原有储存和投递链路，事件只保留动作、结果、安全原因和关联 ID。回调异常与业务事务隔离。启用插件时，业务日志使用单独的 logger，以便在 Worker 常规日志级别为 WARNING 时保留成功样本。
