# ADR 0134 · 首页列表和评论回复通知

主题配置保存首页列表布局、卡片密度和需要隐藏的分类或标签 ID。历史设置默认使用舒展的单列列表。前端在排序、分页前应用首页过滤。文章原地址、归档、搜索和订阅源仍通过自己的内容查询读取。

使用会话和 CSRF 提交的评论记录账号 ID，匿名提交继续沿用原接口。历史评论保留原有作者名。审批使回复公开时，在同一事务登记 `comment.reply_published`。去重键使用回复 ID，恢复已经通过的评论不产生首次通过事件。站内消息和邮件只发给原评论作者。投递前重新核对回复、原评论和原文的可见性，正文只提供通用提示和回复链接。

邮件由读者在账号中心开启。开启需要邮箱已验证，且 Worker 发送前重新核对邮箱验证状态和订阅。管理员可在通知策略中选择站内和邮件渠道，在通知模板中编辑消息文案。

旧博客正文、评论和媒体只在隔离测试库中验证。开发实例交付功能与表结构。
