# ADR 0184 内容编辑器的缓存维护

文章、说说与页面共用按内容标识读取节点状态、重建公开副本和重发副本的接口。读状态需要 `settings:read`，操作需要 `settings:write`，沿用节点维护的鉴权和浏览器 CSRF 边界。未发布内容且各节点无历史副本时只展示状态。

同步以整站不可变公开快照为单位。清除相关缓存从已发布数据重建快照，推进缓存版本，并以目标内容 ID 和公开路径记录失效事件。节点继续提供已有副本直到新版完整到达。强制重新同步重新排队当前公开快照，允许重试次数用尽的节点恢复。

节点状态比较最新公开快照与节点最近确认快照里的目标条目和评论，并检查该内容最近一次手动维护要求的版本。无关内容更新导致的全站版本差异不会单独将本内容标为待同步。后台展示的是后端已确认的投递回执。

上述流程复用既有审计、快照与投递表，无需数据库迁移。部署时先升级后端，内容管理契约为 1.28.0。
